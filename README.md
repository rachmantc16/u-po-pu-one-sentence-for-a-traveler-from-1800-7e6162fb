A program that writes one sentence, in words a person from 1800 already knew, explaining the modern internet as a single post road joining every home on Earth — bearing letters, books, pictures, and voices in a breath, so you may read any library or speak to any soul as if they stood beside you. The program is deterministic and writes the sentence to `entry.txt` in the output directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`).

## Run it

```sh
node main.ts
```
